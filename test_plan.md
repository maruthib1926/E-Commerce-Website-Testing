
# Test Plan

## 1. Project Name
E-Commerce Website Testing Project

## 2. Application Under Test
SauceDemo

## 3. Testing Objective
To verify the functionality of the e-commerce application and identify defects through manual testing.

## 4. Scope of Testing

### In Scope
- Login functionality
- Product display
- Add to Cart
- Cart verification
- Product sorting
- Checkout process
- Form validation
- Order confirmation

### Out of Scope
- Payment gateway testing
- Performance testing
- Security testing

## 5. Testing Approach
Manual Testing

## 6. Test Environment
- Application: SauceDemo
- Browser: Google Chrome
- Operating System: Windows
- Testing Type: Manual Testing

## 7. Entry Criteria
- Application should be accessible.
- Valid test credentials should be available.
- Test cases should be prepared.

## 8. Exit Criteria
- Planned test cases should be executed.
- Test results should be documented.
- Observed defects should be reported.

## 9. Test Deliverables
- Test Plan
- Test Cases
- Bug Report
- Test Execution Report
